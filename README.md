# Financial Dashboard

## Overview
This project is a financial analysis dashboard built using Power BI. The dashboard analyzes insurance company financial performance using KPIs such as revenue, assets, liabilities, net income, expenses, dividends, and profitability ratios.

- Power BI

---

## KPIs Included
- Total Revenue
- Total Assets
- Total Liabilities
- Total Net Income
- Profit Margin
- Return on Assets (ROA)
- Debt Ratio
- Dividend Payout Ratio

---

## Dashboard Features
- Revenue trend analysis
- Expense trend analysis
- Net income analysis
- Assets vs liabilities comparison
- Dividend distribution analysis
- Company performance comparison

---

## Business Insights
- Revenue and profitability increased significantly around 2020.
- A few companies dominate total revenue and dividend distribution.
- Debt ratio indicates heavy reliance on liabilities financing.
- Profit margin shows healthy profitability performance.
